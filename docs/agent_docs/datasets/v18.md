# v18 Dataset Routing

## Purpose
Load this for requests about the `v18` dataset: raw or derived paths, train/val/test splits, COCO annotations, transforms, normalization, target construction, manifests, or wiring `v18` into training/evaluation configs.

Do not load this for FLIR-private/proxy analysis, BigEarthNet/Sentinel-2 data, or RegionDiff/STAY behavior unless the user also says the dataset piece is `v18`.

## Decision/routing notes
Use `rg -n "v18|dataset_id|normalization_mode|annotations_path" src configs tests docs` before editing. For path and split resolution, inspect `src/core/data/dataset_targets.py` and `src/core/data/training_data.py`. For image scaling, inspect `src/core/normalization.py` before changing transforms. For labels, boxes, captions, or layout targets, inspect annotation and layout dataset code instead of trainer code first.

`dataset_id: v18` fixes `normalization_mode = raw_uint16_percentile`; a finetuned VAE trained under a different normalization (e.g. `per_image_minmax`) requires the FM input normalization to match it — there is currently no per-run `normalization_mode` override for `dataset_id`-backed datasets (would need wiring in `resolve_training_data`). Disk latent caching (`src/core/data/latent_cache.py`) includes `normalization_mode` as a first-class cache-key component, so minmax- and percentile-encoded latents never cross-contaminate. TensorBoard image display is normalization-aware via `denorm_for_display` (`src/core/normalization.py`): percentile reverse-normalizes to the raw sensor domain before plotting; `per_image_minmax` (non-revertible) plots `[-1,1]->[0,1]` directly.

## Modification guidance
Dataset loading changes usually belong in `src/core/data/`, path defaults in `src/core/paths.py` or dataset target wiring, and YAML overrides under the matching `configs/` area. Do not put dataset logic into root wrappers such as `train_flow_matching.py`, `adapt_stable_diffusion.py`, or `generate_datasets.py`. Do not touch `archive/`, `ControlNet/`, `src/diffusers/`, or nested checkout-like trees unless explicitly requested.

## Validation guidance
Run the narrowest relevant check: `python -m pytest tests/test_dataset_adapters.py -v`, `python -m pytest tests/test_annotation_fm.py -v`, `python -m pytest tests/test_annotation_layout_dataset.py -v`, `python scripts/checks/check_named_dataset_loader.py`, or `python scripts/checks/check_normalization_equivalence.py`. Avoid training, generation, and Slurm validation unless explicitly asked.
